# Atomurus UI V2 — Home

**Scope:** Prompt 06. `index.html` uses UI V2 tokens. Auth, Stripe, and tool chemistry are unchanged. `/app` stays a public guest workspace.

## What changed

- Home loads `assets/ui/index.css` and [`assets/layouts/home.css`](../assets/layouts/home.css).
- Four pillars: **Explore** → `explore.html`, **Visualize** → `viewer/atomic-models.html`, **Solve** → `calculators.html`, **Study** → `/app`. Hero still opens the periodic table (green science CTA).
- HUD copy is gone from the primary UI: no version pill, no `periodic.tbl · live`, no “4 live / 5 Calculators / 5 instruments”. `.data-strip` and `.lc-statusbar` stay in the DOM (public chrome already hides them).
- Counts come from [`assets/product-catalog.js`](../assets/product-catalog.js), generated by `tools/build-product-catalog.js` from live HTML/catalogs (elements, calculators, molecules, atomic models, articles). Fallback numbers in HTML match the last generated catalog.
- `lang-pt-pending` no longer hides `[data-i18n]` on Home. Portuguese still sets `lang="pt-BR"`; English fallbacks stay visible until `i18n.js` applies. Theme-icon swap CSS and `html.lc-loading` stay.

## Catalog

`uniqueAttr` reads markup only (scripts stripped) so calculator `data-target` in JavaScript is not counted. Current derived counts: 118 elements, 8 calculators, 42 molecules, 5 atomic models, 8 articles, 47 3D models (atomic + molecules).

## What this step does not do

- Explore hub, calculators, table, viewer, `/app` restyle
- Removing `public-shell.css` / hoist
- Replacing `lang-pt-pending` on every other page (Prompt 14)
- Protecting `/app`

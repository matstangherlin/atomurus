Modelo de Bohr

O problema que resolveu

A instabilidade do modelo de Rutherford e a explicação das linhas espectrais do hidrogênio (espectro de Balmer) — linhas discretas no UV e visível que a física clássica não podia explicar.

O modelo

Os elétrons só podem existir em órbitas definidas (níveis de energia) — sem emitir radiação enquanto nelas. Ao saltar para uma órbita mais interna, emitem um fóton de energia exatamente igual à diferença entre os níveis (E = hν). Ao absorver energia, saltam para órbita mais externa.

Como foi descoberto

Niels Bohr (1885–1962), físico dinamarquês e discípulo de Rutherford, aplicou a teoria quântica de Planck ao modelo nuclear. Calculou as frequências das linhas espectrais do hidrogênio com precisão nunca antes vista. Nobel de Física 1922.

Aplicação prática

O modelo de Bohr explica a distribuição eletrônica (K, L, M, N…), a camada de valência, os espectros de emissão (por que o néon de um letreiro é vermelho-laranja) e é a base para entender ligações químicas. É o modelo ensinado no ENEM e em vestibulares brasileiros.

Limitação

Só funciona perfeitamente para o hidrogênio (1 próton, 1 elétron). Para átomos multieletrônicos, as previsões ficam imprecisas. Os elétrons não "orbitam" realmente — é uma simplificação clássica de um fenômeno quântico.

Redesign de interface · Round 01

Um laboratório limpo,
com foco no elemento.

A página da tabela periódica acumulou quatro barras de interface empilhadas, dez categorias na legenda, cinco abas e um modal pesado. Este protótipo propõe uma única barra de comando, uma tabela que ocupa a tela e um painel lateral para explorar o elemento sem perder o contexto.

Problema — densidade de funções na página principal
Escopo — tabela periódica · visões · comparador · visualizador 3D
Dados reais — 118 elementos · 10 famílias
Status — protótipo de alta fidelidade, sem backend

Diagnóstico — o que polui a página atual

4 barras empilhadas
Topbar + data-strip + header + legend/download disputam altura antes da tabela.
Navegação duplicada
Abas internas (heatmap, trends, compare, isótopos) competem com a sidebar e com a barra de ações.
Modal pesado no detalhe
O modal cobre a tabela inteira; cada navegação é um ir e voltar, sem contexto.
Funções escondidas no rodapé
Configurações de visual (tamanho, massa, f-block, heatmap) ficam em outra página, longe de onde são usadas.
Legenda com 10 itens em linha
A legenda inteira ocupa uma linha só para filtros que poderiam ser chips compactos.
Status espalhado
Data-strip + breadcrumb + rodapé repetem a mesma informação em três lugares diferentes.

Princípios do redesign

01

Uma barra, um lugar para cada coisa

Busca, visão, exportar e tema vivem na mesma command bar. Chega de topbar + data-strip + tabs + download empilhados.

hierarquia
02

A tabela é o produto

Ela ganha a tela. Chrome recolhível, chips de filtro compactos e status discreto no rodapé do palco.

foco
03

Detalhe em painel, não em modal

O elemento abre num drawer lateral. A tabela continua visível — dá para navegar entre elementos e comparar sem fechar nada.

contexto
04

Filtro por chips com contagem

A legenda vira chips com número de elementos por família — escaneável, rolável e recolhível em um clique.

legibilidade
05

Comparar é um gesto, não uma página à parte

“Fixar” um elemento na tabela e no drawer cria uma trilha de comparação visível. O comparador já vem preenchido.

fluxo
06

Modo foco para estudar e exportar

Um clique esconde todo o chrome e deixa só a tabela — ideal para impressão, apresentação ou estudo puro.

estudo
